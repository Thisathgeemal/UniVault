# Evidence guide: wallet offer QR code screen (S2, Sprint 1 carry-over)

What to open and click for each screenshot of the wallet offer screen (Decision 021,
[docs/frontend/issuer-portal.md](../../frontend/issuer-portal.md) §11,
[docs/api/credential-offers-api.md](../../api/credential-offers-api.md)). Save each one in this
folder under the file name given.

## Before you start

1. Two PowerShell terminals:
   - `cd backend; npm run db:seed; npm run keys:init; npm run dev`: API on
     http://localhost:4000. For shots 7 and 8, restart it with a short offer lifetime first:
     `$env:CREDENTIAL_OFFER_TTL_SECONDS = '75'; npm run dev` (and
     `Remove-Item Env:CREDENTIAL_OFFER_TTL_SECONDS` afterwards).
   - `cd issuer-portal; npm run dev`: portal on http://localhost:5173 (a development build:
     the "Developer details" panel is visible).
2. Sign in as the **admin** `admin@serendib-trading.example` (the development seed password
   that `npm run db:seed` prints).
3. Use Chrome or Edge, a normal window of about 1280 × 800, zoom 100%.
4. **The QR code and the developer panel contain a working one-time code.** Take these shots
   only on the local development database, and press **Cancel offer** (or let it expire)
   afterwards. In DevTools shots, crop or blur the session token value.
